# SoftPlace
Курсоовая работа. Реализация на Go (backend). Вариант: "Фабрика мебели "Мягкое место""

## Customer service quick start

```bash
make customer-run
```

Docker/Compose:

```bash
make customer-compose-up
make customer-compose-migrate
make customer-compose-logs
make customer-compose-down
```
